# Predicting Eligibility for NSAP Using Machine Learning

## 📌 Project Overview
This project predicts the eligibility of applicants for the National Social Assistance Programme (NSAP) using Machine Learning. The model analyzes applicant details and predicts the appropriate welfare scheme based on eligibility criteria.

This project was developed as part of the IBM SkillsBuild/Edunet Foundation program using IBM Cloud services.

## 🎯 Problem Statement
The National Social Assistance Programme (NSAP) provides financial assistance to eligible citizens. Manually verifying applications is time-consuming and prone to errors. This project automates the eligibility prediction process using Machine Learning.
